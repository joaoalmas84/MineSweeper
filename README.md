# 💣 Minesweeper in React + TypeScript

A modern web-based recreation of the classic **Minesweeper** game, built using **React** and **TypeScript**. It supports multiple difficulty levels, responsive UI, and core gameplay logic that mirrors the original experience.

## 🧰 Tech Stack

- React
- TypeScript
- JavaScript (ES6+)
- Vite (or Create React App, depending on your setup)

## 🚀 Features

- ✅ **Three difficulty levels**: Basic (9×9), Intermediate (16×16), and Advanced (30×16)
- ✅ **Left/right click logic**: Reveal cells or mark them with flags or question marks
- ✅ **Auto-reveal of empty cells** using recursive logic
- ✅ **Win/loss detection** with game reset option
- ✅ **Real-time timer and flag counter**
- ✅ **Responsive design** with an optional instruction panel
